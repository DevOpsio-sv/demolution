# RAZLOM

Работен сайт за събаряне и демонтаж в София, област Ловеч и област Плевен. Публичното име е **RAZLOM**. То не е потвърдено като юридическо лице или регистрирана марка и не замества данните на администратора.

Сайтът е статичен Astro проект с една начална страница, страници за поверителност и бисквитки, и Cloudflare Pages Function за формата за запитване. Няма отделни SEO страници за услуги или градове.

Този проект **не е готов за обявяване**, докато не се попълнят домейнът, юридическите данни и получателят на запитванията.

## Локална разработка

Astro 7.4 изисква Node.js `>= 22.23.4`. Подразбиращият се Node 22.22.3 спира с грешка. На тази машина работи Node 24.15.0:

```powershell
nvm use 24.15.0
npm install
npm run dev
```

| Команда | Какво прави |
| --- | --- |
| `npm run dev` | Локален сървър |
| `npm run build` | Статичен билд в `dist/` |
| `npm run preview` | Преглед на билда |
| `npm run check` | Проверка на типовете |
| `npm test` | Проверка на валидацията и функцията за запитване |

Ако `PUBLIC_SITE_URL` липсва, билдът предупреждава и ползва `http://localhost:4321` за canonical и sitemap. Преди публикуване задайте реалния адрес.

## Cloudflare Pages

Адаптер за пълен SSR не се ползва. Страниците са статични. Формата е `functions/api/contact.ts` и се изпълнява като Pages Function.

В настройките на Pages проекта:

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: `22.23.4` или `24` (`NODE_VERSION`)
- Root directory: коренът на хранилището, за да бъде намерен `functions/`

`wrangler.toml` сочи изхода към `dist`. Секрети не стоят във файла.

### Променливи

Копирайте `.env.example`. В Pages ги въведете като environment variables. Не ги комитвайте.

| Променлива | Роля |
| --- | --- |
| `PUBLIC_SITE_URL` | Каноничен адрес без наклонена черта накрая, например `https://example.com` |
| `RESEND_API_KEY` | Ключ за Resend, ако имейлът минава оттам |
| `CONTACT_FROM_EMAIL` | Потвърден подател при Resend |
| `CONTACT_TO_EMAIL` | Пощата, която получава запитването |
| `LEAD_WEBHOOK_URL` | Алтернатива: ваш HTTPS адрес, който приема JSON |
| `LEAD_WEBHOOK_SECRET` | По желание, `Authorization: Bearer` |
| `ALLOWED_ORIGINS` | Допълнителни позволени origin-и, разделени със запетая |

Попълнете **или** Resend (`RESEND_API_KEY` + двата имейла), **или** `LEAD_WEBHOOK_URL`. Ако няма нито едното, формата връща грешка и казва на човека да се обади. Запитването не се пази и не се изхвърля тихо.

Имейл доставката **не е пробвана** от край до край. Няма свързан акаунт.

Resend обработва текста извън вашия сървър. Преди да го включите, впишете го в политиката за поверителност. Webhook към частен или localhost адрес се отказва.

### Домейн

1. Създайте празно отдалечено хранилище и го свържете. Адрес не е измислен тук.
2. В Cloudflare създайте Pages проект от това хранилище.
3. Задайте build command и output directory, както е по-горе.
4. Задайте променливите, включително `PUBLIC_SITE_URL`, и пуснете нов билд.
5. Добавете домейна в Pages.
6. Изберете един каноничен хост и го сложете в `PUBLIC_SITE_URL`.
7. HTTPS идва от Cloudflare. Не изключвайте „Always Use HTTPS“.
8. Другият хост (`www` или голия домейн) пренасочете с правило към каноничния. Няма `_redirects` файл, защото домейнът още не е избран.
9. След билда с реалния `PUBLIC_SITE_URL` проверете `sitemap-index.xml`, canonical и Open Graph.
10. Отворете сайта, формата и телефона на телефон.

Страниците излизат като `poveritelnost/index.html`. С `trailingSlash: "never"` каноничният адрес е `/poveritelnost`. Pretty URLs на Pages обикновено обслужват и двата вида. След пускане проверете, че няма две индексирани версии.

## Форма

Полета: име, телефон, населено място, вид на обекта, описание. Няма качване на файлове. Снимки се пращат по Viber или се описват по телефона.

Защити: лимит на тялото 20 KB, проверка на полетата, honeypot, времеви капан, до 5 изпращания за 10 минути през `caches.default` (ако кешът липсва, лимитът се пропуска), проверка на origin. Спамът получава неутрален успех и не се препраща. Грешките в лога не включват текста на запитването.

Без JavaScript формата прави обикновен POST и при успех отива на `/blagodarim`. Със JavaScript отговорът е JSON в самата страница.

Локалният `astro preview` **не** изпълнява Pages Function. Затова там изпращането показва грешка и телефон. За локална проба на функцията използвайте Wrangler Pages, след като има получател.

Политиката в `/poveritelnost` и страницата `/biskvitki` са чернови от 17 ноември 2026 г. Маркираните празнини не бива да се представят като попълнени. Наличието на тези страници не прави сайта GDPR-съвместим.

Няма банер за бисквитки, защото няма статистика, реклама, външни шрифтове или `localStorage`. Ако по-късно се включи статистика или защита, която пише бисквитка, тя трябва да стои изключена до съгласие, а страницата да се обнови. След публикуване проверете реалните бисквитки в чист браузър, включително Bot Fight Mode.

Часове за отговор, брой обекти, екип, лицензи, застраховка и машини не са посочени, защото не са потвърдени. Не добавяйте такива твърдения без документ.

## Снимки

Големият кадър в секцията с обекти е реална снимка на тухлена постройка с разкрит покрив. Останалите кадри са илюстративни и са надписани така. Не са изпълнени обекти. Източниците им са в `src/data/credits.ts` и във футъра.

Реален обект се добавя в `src/data/projects.ts`: заглавие, услуга, потвърдено населено място или `null`, и снимка. Сложете `illustrative: false` само когато кадърът е наистина от работата. Двойка преди/след се попълва с `before` и `after` само ако и двете са истински.

Нови файлове минават през `scripts/build-images.mjs`, който пише AVIF/WebP в `public/images/` и обновява `src/data/photo-manifest.json`.
